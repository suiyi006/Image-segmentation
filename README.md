# Image-segmentation
Image segmentation
## Environment
This repository is built with Python. The required dependencies are listed below:

pip install scipy
pip install ml-collections
pip install tensorboardX
pip install medpy
pip install h5py
pip install matplotlib
pip install tqdm
pip install "numpy<2.0"
pip install einops
pip install PyWavelets==1.3.0
pip install pytorch-wavelets

## datasets
The datasets are all from the Kaggle website. You can conduct corresponding searches on your own. The website is:https://www.kaggle.com

##Tips:
This project is about 2D image segmentation. The project benchmark is TransUNet. The provided code is used to replace the framework in the TransUNet project. The corresponding project for TransUNet is:
https://github.com/Beckschen/TransUNet
